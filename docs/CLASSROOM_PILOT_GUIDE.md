# Classroom Mode — Pilot Guide for Teachers

Fontaine now supports three classroom session modes so you can run activities whether you have zero student devices, a few shared tablets, or one device per student.

## The Three Modes

### 1. Teacher-Led Mode (بقيادة المعلم)

**When to use:** You have a projector/smartboard and zero student devices. The whole class participates together.

**How it works:**
1. Go to **Sessions** and click **New Session**
2. Select your activity and class
3. Choose **Teacher-Led** mode
4. You are redirected to the **Projector View** — a full-screen dark page designed for classroom display
5. The question appears in large text on screen
6. Students discuss and shout answers. You click the answer the class agrees on (for quiz/true-false/vocabulary) or use the correct/incorrect buttons (for other types)
7. The system scores automatically and shows the result
8. Use **Next** to advance, **Previous** to go back, or **Reveal Answer** to show the correct answer without moving on
9. At the end, a results screen shows accuracy per question

**No student devices needed.** No join code, no waiting room. Just project and teach.

### 2. Team Mode (فرق)

**When to use:** You have a few shared devices (e.g., 6 tablets for 24 students). Students work in small groups.

**How it works:**
1. Create a new session and choose **Team** mode
2. Set the number of teams (2–8). Default Arabic team names and colors are assigned automatically
3. Share the join code or QR code with students
4. Students join on their shared device and pick their team
5. The game plays like individual mode — but scores are aggregated per team
6. The leaderboard shows team rankings alongside individual rankings

**Tips for teams:**
- With 6 devices and 24 students, create 6 teams of 4
- Let students decide who holds the device and rotate each round
- Team names can be customized before the game starts

### 3. Individual Mode (فردي)

**When to use:** Every student has their own device. This is the default — unchanged from before.

**How it works:** Same as always. Create session → share code → students join → play → see leaderboard.

## Choosing the Right Mode

| Scenario | Recommended Mode |
|----------|-----------------|
| 0 devices, projector only | Teacher-Led |
| 6 shared devices, 24 students | Team (6 teams) |
| 24 devices, 24 students | Individual |
| Mixed — some with devices, some without | Team (put device-less students on teams with devices) |

## Projector View Controls

When running a Teacher-Led session, the projector view gives you these controls:

- **Pause / Resume** — Freeze the timer and game
- **Previous** — Go back to the prior question
- **Reveal Answer** — Show the correct answer without moving to the next question
- **Award Point / Remove Point** — Manually adjust the class score
- **Show Explanation** — Display the question's explanation text
- **Next** — Move to the next question
- **End Session** — Finish and show results

## Leaderboard

- **Teacher-Led:** No leaderboard (it's a whole-class activity). Results show class accuracy.
- **Team:** Team leaderboard + individual leaderboard. You can hide the leaderboard when creating the session by toggling "Show Leaderboard" off.
- **Individual:** Individual leaderboard (same as before).

## Session Results

After a session ends:
- **Teacher-Led** results show: total questions, correct count, total score, accuracy percentage, and per-question breakdown
- **Team** results show: team rankings with scores + individual rankings
- **Individual** results show: individual rankings, class average, participation rate, per-question stats, and students needing support

## Tips for Pilots

1. **Test the projector view first** — Open it on your laptop to check text size and readability before class
2. **For team mode, pre-plan your groups** — Decide on team count before the session
3. **All 8 game types work with all modes** — Quiz, true/false, matching, sentence builder, story ordering, grammar detective, find the mistake, and vocabulary
4. **You don't need to configure many settings** — Just pick the mode and optionally set team count. Everything else has sensible defaults
5. **Individual mode is completely unchanged** — Nothing about the existing system has changed. If you don't select a mode, it defaults to individual
